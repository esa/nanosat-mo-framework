======================
NMF on OPS-SAT mission
======================
The NMF is the default software framework for experimenters on `OPS-SAT <https://www.esa.int/Our_Activities/Operations/OPS-SAT>`_.
The OPS-SAT mission was launched in December 2019, and the NanoSat MO Framework was first executed in space in 2020.
This chapter describes the differences between the NMF SDK execution environment and the OPS-SAT deployment, including differences in the test setup.
