========
Javadoc
========

The complete Java API reference is generated from the NMF source by
the ``javasphinx-apidoc`` step in the docs build.

After running the docs build, the generated Javadoc tree is available
under ``docs/source/javadoc/`` and is indexed in the same Sphinx
output as this manual. Browse it for full class-by-class detail —
including the generated MO API classes, the Supervisor and Connector
composites, and the M&C adapter base classes.

For the source of each class, see the corresponding Java file under
``core/`` (framework) or ``mission/``, ``sdk/``, and
``nmf-mission-barebone/`` (deployment-side code).
