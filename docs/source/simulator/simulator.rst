=================
CubeSat Simulator
=================

.. toctree::
   :hidden:
   :caption: Table of contents

   configure

The NMF includes a CubeSat simulator modelled on the `OPS-SAT <https://www.esa.int/Our_Activities/Operations/OPS-SAT>`_ spacecraft.
The simulator is used, for example, when starting the NanoSat MO Supervisor with simulator support, as described in the :doc:`../eclipse` and :doc:`../netbeans` guides.
It provides a broad range of data, from basic telemetry such as system time to GPS and ADCS information, enabling apps to be tested against data that closely approximates that of a real spacecraft.

The simulator's behaviour can be tailored to specific test scenarios through configuration. See :doc:`configure` for details.
