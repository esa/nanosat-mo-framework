=========================
Configuring the simulator
=========================

.. contents:: Table of contents
    :local:

The simulator is integrated into the Supervisor Sim. On its first launch, a set of configuration files with default values is generated in the working directory.

General configuration options
-----------------------------
The following parameters can be set to control general simulator behaviour:

- Activation of internal model processing
- Simulated time increment
- Real-time factor
- Keplerian orbital elements
- Use of the Orekit library
- Updating of GPS constellation TLEs from the Internet
- Celestia visualisation and the port to be used
- Simulation start and end dates
- Logging levels

Platform configuration options
------------------------------
The simulator's platform services can be configured through the following options:

- **Platform simulation mode** (``sim`` or ``hybrid``) — determines whether all spacecraft data is generated by simulation, or whether some components (e.g. the camera) use real hardware.
- **x.adapter**, where ``x`` is one of ``{camera, optrx, gps, iadcs, sdr, power}`` — selects the adapter class to be used (simulated or real OPS-SAT adapter), depending on the platform simulation mode.
- **camerasim.imagemode** — ``Random`` or ``Fixed``. Determines whether the camera simulator returns the same image on every call or a random image from a directory.
- **camerasim.imagefile** — absolute path to the image to be used when ``camerasim.imagemode`` is set to ``Fixed``.
- **camerasim.imagedirectory** — absolute path to the directory to be used when ``camerasim.imagemode`` is set to ``Random``.

File-based configuration
------------------------
On the first launch of the Supervisor with simulator, a set of configuration files is generated in its working directory. Resources are also unpacked and logging is initialised in a directory named ``.ops-sat-simulator`` under the user's home directory.

The two main configuration files are:

- ``_OPS-SAT-SIMULATOR-header.txt`` — controls the general configuration options listed above.
- ``platformsim.properties`` — controls the platform configuration options.

Both files use Java properties syntax: each option is modified by editing the value on the right-hand side of the assignment. The files must reside in the simulator's execution directory.

UI-based configuration
----------------------
The simulator is, in essence, a TCP server that can be run either locally or on a remote machine. The OPS-SAT spacecraft simulator includes a client GUI application that connects to a running simulator instance, allowing commands to be issued and the simulator configuration to be modified.

Running the UI
^^^^^^^^^^^^^^
To run the simulator GUI from NetBeans, right-click the ``ESA OPS-SAT - Spacecraft Simulator`` project and select ``Run``. When prompted for the main class, select ``opssat.simulator.main.MainClient``. This launches the client UI.

To run the simulator UI from Eclipse, import the ``SimClient`` launch configuration from ``sdk/launch-configs`` and update the variables as described for the Supervisor and the CTT. The project can then be started by executing the imported run configuration.

Connecting to the simulator
^^^^^^^^^^^^^^^^^^^^^^^^^^^
When the server and client are running on the same machine, no additional configuration is required, as the client connects to localhost by default. When the simulator runs on a separate machine, the IP address and port (``11111`` by default) must be entered in the centre of the window. Running the server and client on the same machine is recommended whenever sufficient local resources are available.

General configuration
^^^^^^^^^^^^^^^^^^^^^
After connecting to the server, several configuration options — including the real-time factor and the simulation start time — are available at the top of the window. Clicking ``Edit Header`` opens a dialog that exposes the same parameters along with the simulation start and end dates. Clicking ``Submit to server`` transmits the updated values and applies them to the running configuration.

Platform configuration (WIP)
^^^^^^^^^^^^^^^^^^^^^^^^^^^^
At present, the only platform service configurable through the UI is the camera service. Its settings are accessed via the ``Camera Settings`` tab, which allows selection of a fixed image or a random image from a directory, specification of the image or directory path, submission of changes, and inspection of the currently applied settings.

.. note::

   When the simulator runs on the local machine, clicking the ``Browse`` button opens the local file explorer.
   When the simulator runs on a remote server, SFTP must be enabled on that server so that a basic SFTP file browser can be displayed.
