NanoSat MO Framework Documentation
================================================
This is the official documentation for the `NanoSat MO Framework <https://github.com/esa/nanosat-mo-framework>`_, a software framework for developing on-board and ground software for small satellites.
New users are encouraged to begin with the :doc:`quickstart` page, which provides a guided path to building an app that can be deployed on a satellite such as `OPS-SAT <https://www.esa.int/Our_Activities/Operations/OPS-SAT>`_.
